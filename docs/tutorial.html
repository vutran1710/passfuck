Set up your passwords, step by step

This takes about 15 minutes on your Mac and 5 on your iPhone. Do it in order. You can stop at any point and pick up later by typing pf in Terminal.

Pink marks what you type, click or tap. Drawings are simplified, and labels in other apps may differ slightly.

Your Mac

One command starts a guided setup in Terminal. It asks you questions and does the rest.

1

Run the install command

Open Terminal: press Cmd + Space, type Terminal and press Return. Paste this line and press Return:

curl -fsSL https://vutran1710.github.io/passfuck/install | bash

If Homebrew isn't installed yet, it installs that first and asks for your Mac's login password. Nothing shows while you type a password in Terminal. That's normal.

Terminal
~ % curl -fsSL https://vutran1710.github.io/passfuck/install | bash
==> Downloading passfuck to ~/.passfuck
==> Installed. Run 'pf' any time to re-open setup.

passfuck setup — safe to re-run; finished steps are skipped.
2

Choose your master phrase

Before you start typing, write your phrase on paper. Then:

  • Enter your name and email. They're saved for you, so you don't need to remember them.
  • Type your phrase, press Return, and type it again.
  • Wait about ten seconds while your key is made.

Your phrase won't appear as you type. If the two don't match, it stops and you can start again.

Let it set up this Mac

This part is mostly automatic. It installs the tools, downloads your vault and turns on syncing.

If you're not logged in to GitHub yet, it shows a one-time code:

  • Copy the code and press Return.
  • Your browser opens GitHub. Paste the code and approve.

4

Add Browserpass to your browser

The setup asks which browsers to open. Say yes, and the Browserpass page opens in Brave or Chrome.

  • Click Add to Brave (or Add to Chrome), then confirm.
  • Click the puzzle-piece icon in the toolbar and pin Browserpass so it's always visible.
  • Go back to Terminal and press Return.

Add Raycast for every other app

Raycast is a free search bar for your Mac. It lets you grab a password from any app, even ones that hide their login fields.

  • Say yes when asked to install it. When Raycast opens, pick a keyboard shortcut for it.
  • The Pass extension page opens. Click Install.

6

Export the passwords you already have

Save your existing passwords to a file, from wherever they're stored now:

  • Brave: go to brave://password-manager/settings and click Export passwords.
  • Chrome: chrome://password-manager/settings, same button.
  • Apple Passwords app: File, then Export All Passwords.

The file contains every password in plain text. The next step deletes it once it's imported.

7

Import them under your own aliases

Drag the exported file into the Terminal window and press Return. For each password, it shows you the site and asks for an alias: a short name only you will recognise.

  • Use the alias to find the password later, like gh or tv.
  • A slash makes folders, like work/code.
  • Press Return with no alias to skip an entry.

The alias is the only thing people can see in your public vault. The site, username and password are sealed inside.

9

Send your keys from the Mac

Back in the Terminal setup, answer yes at the iPhone step. You can also run pf phone any time. A folder called passfuck-for-iphone opens on your Desktop.

  • Select everything in it, right-click, choose Share, then AirDrop, and pick your iPhone.
  • On the iPhone, save the files to Files.

These files can unlock your vault together with your phrase. Delete them once you're done, as shown in step 12.

10

Import the keys into the app

Open Pass and go to its Settings.

  • Tap PGP Key and choose to import from Files. Pick 1-public-key.asc, then 2-private-key.asc.
  • When it asks for the passphrase, enter your master phrase and let it remember it. Face ID protects it from then on.
  • Tap SSH Key, import from Files, and pick 3-ssh-key.

Connect your vault

In Settings, tap Password Repository and fill in exactly what's in the README.txt file:

  • Username: git
  • Authentication: SSH Key

Tap Save. Your passwords download, and you'll see your aliases listed.

Turn on AutoFill, then clean up

Open the iPhone's Settings app, go to General, then AutoFill & Passwords, and switch Pass on.

Then delete the passfuck-for-iphone files from the Files app. Back in Terminal, press Return and the copy on your Mac is deleted too.

The first time after a restart, a Mac window asks for your phrase. After that it's remembered for an hour.

Save a new password

When you sign up somewhere, make the password here first, then paste it into the sign-up form.

  • Mac: in Terminal, pass generate -c alias 24 makes a 24-character password and copies it. Then pass edit alias lets you add login: and url: lines.
  • iPhone: in the Pass app, tap +, choose an alias, and use its password generator.

Either way it syncs to the other device by itself.

Terminal
~ % pass generate -c shop 24
Copied shop to clipboard. Will clear in 45 seconds.

~ % pass edit shop
  (an editor opens; add these under the password)
  login: me@vutr.io
  url: https://shop.example.com

That's it

From now on, the only thing to remember is your phrase. On a new Mac, run the install command again and type the phrase. Everything comes back.

Something look different from these drawings? Run pf again. It skips what's done and repeats only what isn't.
